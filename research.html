Research Interests

01

Stacking Sequence Determination using 4D-STEM in TMDs

Developed a novel methodology to determine stacking sequences layer-by-layer by using scanning nanobeam diffraction. Characterization of stacking sequence is conducted with electronic properties using Kelvin-Probe Force Microscopy (KPFM) and Low-Frequency Raman spectroscopy.

02

Machine Learning & Deep Learning Methodologies for TEM Analysis

Implemented a model to extract individual coordinates for each atomic column in atomic STEM images using saliency-based clustering. Utilized the extracted coordinates for quantification tasks such as strain and defect analysis.

03

Displacement Vector Field Mapping in Epitaxially Grown TMD Heterostructures

Characterized structural variations including Moiré lattice defects in CVD-grown MoS₂/WSe₂ heterostructures. Correlated strain relaxation with Moiré lattice defect evolution via displacement vector field mapping using 4D-STEM.
